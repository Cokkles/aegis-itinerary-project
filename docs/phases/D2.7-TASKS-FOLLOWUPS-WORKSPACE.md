# D2.7 — Tasks and Follow-ups Personal Workspace

## Contract boundary

D2.7 adds capability-gated, authenticated Google Tasks controls to the existing
AEGIS backend. Google Tasks remains canonical. Windows may retain an
identity-protected last-known-good cache, but it never becomes an independent
task authority.

The backend version is `2.7.0` and advertises:

- `task_workspace_v1` — bounded active tasks across up to 25 task lists;
- `tasks_history_v1` — completed tasks from a caller-selected 1–30 day window;
- `task_lists_v1` — task-list creation and rename;
- `task_action_v1` — create, edit, delete, complete, restore, and follow-up
  promotion operations;
- `followups_v1` — durable Notes-derived follow-ups and lifecycle state.

Every route passes through AUTH-1 and requires `tasks.read`, `tasks.write`,
`dashboard.read`, or `spark.write` as appropriate. Additional Google OAuth
consent is not introduced; the deployment continues using the existing enabled
Google Tasks advanced service.

## Safety model

- Task completion retains the Windows five-minute local undo queue.
- Create, edit, restore, list creation, and list rename are explicit mutations
  and are not automatically retried.
- Task deletion requires an explicit Windows confirmation and is not retried.
- Task-list deletion is deliberately excluded because it could remove an entire
  list and all of its tasks.
- HORIZON/Notes follow-ups appear automatically in the Tasks workspace, but
  AEGIS does not silently create Google Tasks. Promotion is an explicit action
  that records a durable `FOLLOW_UP_PROMOTED` marker.
- Resolve and dismiss append lifecycle markers; they do not rewrite or erase
  the original Notes provenance.

## Deployment gate

Deploy the full `apps-script/Code.calendar-prepare-v1.gs` candidate as a new
Apps Script web-app version. Verify `?action=get_capabilities` reports backend
`2.7.0` and all capability flags above before installing the D2.7 Windows
client.

PWA and Android clients remain compatible because existing action names and
response properties are preserved. New properties and actions are additive.
